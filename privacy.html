營運與聯絡窗口

瀏覽官網時的服務連線

官網透過 GitHub Pages 提供頁面與素材；Android 安裝檔由 GitHub Releases 提供。下載區可能向 Supabase 查詢公開的版本資訊。這些服務會接收處理網路請求所需的資訊，例如 IP 位址、瀏覽器資訊及請求紀錄；相關服務也有各自的隱私政策。

本次官網未加入廣告追蹤碼、分析追蹤碼或行銷 Cookie。網站連結至遊戲及第三方平台後，資料處理方式可能不同。

客服信件

你寄送的電子郵件地址、問題描述及附件，會用於回覆、查證問題與提供支援。請只提供與問題相關的資訊，不要寄送密碼、驗證碼或付款卡號。

遊戲登入與雲端存檔

本說明涵蓋台籃模擬器遊戲與官網。遊戲使用 Supabase 提供帳號驗證及雲端資料服務。使用信箱驗證碼或第三方登入時，會處理電子郵件地址、登入提供者的帳號識別及工作階段憑證，用於辨識帳號、登入和跨裝置同步。第三方登入的授權由登入提供者處理；請勿向客服提供第三方帳號密碼或驗證碼。

遊戲會保存球隊名稱、存檔、球員與戰術卡、陣容、比賽紀錄、遊戲資源、獎勵與交易確認紀錄，以提供遊戲進度、避免重複扣款或發獎，並處理異常復原。裝置也會保存登入工作階段、介面偏好及同意紀錄。

營運與故障診斷

遊戲會產生隨機安裝識別碼，並傳送平台與遊戲版本，用於統計安裝及版本使用情況。登入後的營運事件會連結遊戲帳號，包含登入方式、部分頁面使用、聯盟、賽季階段、比賽勝負與比分，以及交易回應狀態、等待時間及處理耗時。這些紀錄用於了解使用情況、改善效能和排查問題。隨機安裝識別碼不是 Apple 的廣告識別碼。

付款與廣告

目前尚未開放現金購買與遊戲廣告。遊戲內以黃金或資金進行的交易會保存資源與獎勵確認紀錄。日後啟用平台內購或廣告前，將依實際提供的服務更新本說明與商店資料揭露。

資料存取與你的要求

帳號資料用於提供遊戲、維護安全及玩家支援。服務供應商會處理提供服務所需的連線及資料，相關說明可參閱 Supabase 隱私政策、Google 隱私政策及Apple 隱私政策。

遊戲內可從「遊戲設定 → 帳號與資訊 → 刪除帳號」提出永久刪除。確認後會刪除登入帳號、球隊、球員卡、資源、戰績與雲端存檔，無法復原。使用 Apple 登入的帳號須一併撤銷 Apple 授權後，才能完成刪除。刪除成功會在遊戲內顯示確認，並登出帳號。如需查詢或更正資料，請聯絡 nutsidea@nutsidea.com；處理前會確認帳號身分。解除安裝或登出不會刪除雲端帳號及存檔。
