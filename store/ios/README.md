# 台籃模擬器｜iOS 正式版上架素材

這套素材以實際遊戲畫面為主，維持「簡約、日式、深藍球場、橘色重點」的視覺方向。

## 可直接上傳

- `6.7/`：2796 × 1290，iPhone 6.9 吋橫向截圖（5 張）
- `6.5/`：2778 × 1284，iPhone 6.5 吋橫向截圖（5 張）
- `marketing/key_art.png`：無文字宣傳主視覺，可作為 App Store 行銷圖或官網素材
- `app_icon_1024.png`：App Store Connect App icon 原始圖
- `app_store_metadata_zh-Hant-TW.md`：繁體中文名稱、副標題、宣傳文字、描述、關鍵字與審核備註
- `asset_manifest.json`：素材尺寸與用途清單

## App Store Connect 貼上順序

1. App 資訊：名稱、副標題、隱私權政策 URL、支援 URL。
2. 版本頁：先上傳 6.7 吋截圖；需要時再上傳 6.5 吋截圖。
3. 依序放入 01 登入、02 陣容、03 更衣室、04 戰術、05 特訓。
4. 貼上 metadata 檔案中的繁中欄位；關鍵字不要把逗號後加空格。
5. 預覽所有裝置尺寸，確認沒有裁到標題、按鈕或球員卡。

素材沒有透明背景，截圖是 JPEG，符合 App Store Connect 截圖格式；遊戲畫面本身仍保持可操作內容，不把 UI 畫死在宣傳圖中。
